Fundamentos Matemáticos
▽
Suma Inferior — Rectángulos izquierdos
▾
Ln = Δx · Σi=0n-1 f(xi)
xi = a + i · Δx
Usa el extremo izquierdo de cada subintervalo para determinar la altura del rectángulo. Para funciones crecientes, este punto siempre da el valor mínimo del intervalo, generando rectángulos que quedan por debajo de la curva y subestiman el área real.
△
Suma Superior — Rectángulos derechos
▾
Un = Δx · Σi=1n f(xi)
xi = a + i · Δx
Usa el extremo derecho. Para funciones crecientes, este punto es el máximo local, produciendo rectángulos que superan la curva y sobreestiman el área. El área verdadera siempre queda entre Ln y Un: Ln ≤ ∫ f ≤ Un.
◇
Suma de Riemann — Punto medio
▾
Mn = Δx · Σi=0n-1 f(x̄i)
x̄i = a + (i + 0.5) · Δx
El punto medio del intervalo equilibra el error: la parte que queda fuera del rectángulo se compensa con la parte interior. Matemáticamente es la aproximación de mayor orden (error O(Δx²)), convergiendo más rápido a la integral exacta que los extremos.
∞
Integral Exacta — Teorema Fundamental
▾
∫ab f(x) dx = F(b) − F(a)
donde F'(x) = f(x) (antiderivada)
El Teorema Fundamental del Cálculo conecta diferenciación e integración. Al aumentar n → ∞, todas las sumas de Riemann convergen a este valor. La librería SymPy calcula la antiderivada simbólicamente y evalúa F(b) − F(a) con precisión exacta.
